# EduRisk Analytics - Lab 01

## Project Theme

EduRisk Analytics - Student Risk Prediction and Monitoring System

## Description

My first Streamlit app for Web App Development for Data Science.
It shows student data, simple metrics, and a sidebar for navigation.

## Features

- Sidebar with three pages: Home, Student Data, About
- Four metrics: total students, average score, average attendance, low score students
- Student data table

## Tools Used

- Python
- Streamlit
- Pandas
- VS Code
- Git and GitHub

## How to Run

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```
